# English Trainer

Личное Android-приложение для расширения словаря. Подробности — в `TZ.md`.

## Быстрый старт
1. Создайте репозиторий на GitHub и загрузите содержимое этой папки.
2. Сгенерируйте базу из 2000 слов и фраз (нужен ключ любого OpenAI-совместимого API):
   ```
   AI_API_KEY=... AI_BASE_URL=https://api.openai.com/v1 AI_MODEL=gpt-4o-mini python tools/gen_seed.py
   ```
   Результат: `assets/seed.json`. Закоммитьте его. Без этого шага приложение использует `assets/starter.json` (30 записей).
   Проверьте файл глазами: ИИ иногда ошибается в переводах и примерах.
3. Push в `main`. GitHub Actions соберёт APK: вкладка Actions → последний запуск → artifact `english-trainer-apk`.
4. Установите APK на телефон. В приложении откройте «Настройки ИИ» и укажите адрес провайдера, ключ и модель.

## Локальная сборка (опционально)
Нужны Flutter 3.22+ и Android SDK:
```
flutter create --platforms=android --project-name english_trainer .
flutter pub get
flutter run
```

## Откуда берутся слова
Три источника, все работают без сети после загрузки:

1. **`assets/words/`** — словарь, разбитый на части (`01_…` — `20_…`). Слова лежат в репозитории. `words_tech.txt` — лексика для разработчиков и сайтов (deploy, bug, pull request, sign up и т. д.). Формат строки: `слово|перевод|пример|уровень`. Добавьте строки, закоммитьте, и при следующей сборке новые слова появятся у пользователя при запуске. Ничего менять в коде не нужно: приложение сравнивает отпечаток файла.
2. **`assets/seed.json`** — большой список, который генерирует `tools/gen_seed.py` через ИИ-API. Запускается вручную: в GitHub откройте Actions → Build APK → Run workflow, включите `gen_seed` и выберите уровень. Ключ хранится в секрете репозитория `AI_API_KEY`. Файл создаётся внутри сборки и в репозиторий не попадает.
3. **Импорт внутри приложения** — «Настройки → Импорт». Можно вставить строки `слово;перевод;пример` или JSON.

Слова, которые вы добавили в приложении или отредактировали, не перезаписываются. Удалённые из файла слова в приложении остаются.

## Настройка GitHub
- Settings → Secrets and variables → Actions → Secrets: `AI_API_KEY` (нужен только для генерации).
- Variables (необязательно): `AI_BASE_URL`, `AI_MODEL`.
- Файл `build.yml` положите в `.github/workflows/build.yml`.
